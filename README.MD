## Project Overview

This project demonstrates a simple CI/CD workflow using Jenkins, Docker, GitHub, and a static HTML website.

The project automates the process of building and deploying a website using a Jenkins pipeline and Docker container.

## Technologies Used

- Jenkins
- Docker
- Git & GitHub
- HTML
- Linux
- AWS EC2

## Project Structure

- `Dockerfile` - Used to build the Docker image
- `Jenkinsfile` - Defines the Jenkins CI/CD pipeline
- `index.html` - Static website page
- `README.md` - Project documentation

## Workflow

GitHub → Jenkins → Docker Build → Docker Container → Website Deployment

## Key Features

- Created a Dockerfile for the website
- Built and managed Docker images and containers
- Created a Jenkins pipeline for automation
- Integrated GitHub with Jenkins
- Deployed the website using Docker
- Performed troubleshooting during deployment
